# Maktaba: offline library search

Maktaba searches every passage of your books by word or by idea, in English, French and Arabic. Once it's installed it runs fully offline. Your books never leave your iPad.

## One-time setup (about 10 minutes, needs internet)

### 1. Unzip
In the **Files** app, tap `maktaba-offline.zip`. You get a folder called **maktaba** with 16 files in it.

### 2. Put the app online with GitHub Pages (free)
1. In Safari, go to **github.com** and create a free account, or sign in.
2. Tap **+** (top right), then **New repository**.
   - Name: `maktaba`
   - Choose **Public**. This is required for free GitHub Pages. Only the app's code is public. Your books are never uploaded.
   - Tap **Create repository**.
3. On the new repository page, tap **uploading an existing file**, or use **Add file → Upload files**.
4. Tap **choose your files**, open the **maktaba** folder, tap **Select**, then **Select All**, then **Open**. Wait until all 16 files are listed. The largest one is about 21 MB.
5. Scroll down and tap **Commit changes**.
6. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, the branch to **main** and the folder to **/ (root)**, then tap **Save**.
7. Wait 1–2 minutes, then refresh. The page shows your app's address, for example `https://YOUR-NAME.github.io/maktaba/`.

### 3. Install it on the iPad
1. Open that address in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. From now on, always open Maktaba from its **Home Screen icon**. Books added in a Safari tab are kept separately from books added in the installed app.

### 4. Download the idea model (once, on Wi-Fi)
In the app, tap **Download idea model** (about 120 MB). When the purple card disappears, the top-left line says **"App saved for offline use · idea model on this device"**. Everything now works without internet.

## Everyday use
- **Add books:** tap **Add books**, then **Browse**, and pick PDFs or EPUBs from GoodReader (On My iPad) or any Files folder.
- **New versions:** adding a newer version of a book replaces the older one automatically, with an Undo button. Exact copies are skipped.
- **Idea search:** after you add a book it is word-searchable at once. Idea search becomes ready after a short background step (about 1–2 minutes for a 300-page book). The shelf shows the progress.
- **Back up:** tap **Save a backup** now and then and save the file to Files. **Restore backup** brings everything back, for example on a new iPad.

## Notes
- Scanned PDFs (pictures of pages) have no text to search. Run them through a text-recognition (OCR) tool first.
- To update the app later, upload the new files to the same repository. The installed app picks up the update the next time it's opened online.
